# 🎵 PORO - Project SEKAI Game Site 🎵

POROは、Project SEKAIをテーマにした対話型音楽ゲームウェブサイトです。

## 機能

- 🎮 **インタラクティブゲームプレイ** - クリックしてノーツを叩く
- 🎵 **複数の楽曲** - Tell Your World、Hare Hare Yukai、World is Mine、Senbonzakuraなど
- 📊 **スコアシステム** - スコア、コンボ、HPを追跡
- ⭐ **難易度選択** - EASY、NORMAL、HARD、EXPERTから選択可能
- 📱 **レスポンシブデザイン** - モバイルとデスクトップに対応

## 使い方

1. **楽曲を選択** - 右側の楽曲一覧から好きな曲を選びます
2. **ゲーム開始** - 「ゲーム開始」ボタンをクリック
3. **ノーツをタップ** - 下に降ってくるノーツをクリック（またはスペースキー）
4. **スコアを稼ぐ** - コンボを続けてハイスコアを目指す

## ゲームルール

- **ノーツをヒット** - +100ポイント（コンボボーナス付き）
- **ノーツをミス** - HPが5%減少、コンボがリセット
- **HP 0** - ゲームオーバー
